# Isobar

Минималистичная погода для Windows: 18 тем со своими раскладками (включая Pixel OS), 13 стилей радара, анимированная погода и виджеты на рабочем столе.

## Установка

Скачайте `Isobar-Setup-<версия>.exe` из последнего релиза: https://github.com/dcvke/isobar-releases/releases/latest

Установщик ставит приложение для текущего пользователя, права администратора не нужны. Windows может показать предупреждение SmartScreen, потому что установщик не подписан сертификатом: нажмите «Подробнее» и «Выполнить в любом случае».

## Обновления

Приложение само проверяет этот репозиторий при запуске и каждые 4 часа, скачивает новую версию в фоне и предлагает перезапуститься.

Исходный код хранится в отдельном приватном репозитории.
